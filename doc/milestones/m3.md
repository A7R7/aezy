## 已交付

### Worktree identity 与创建

- `describeProject()` 区分 `local` / `worktree`，并公开 Git dir/common dir identity。
- 创建只接收 1-64 字符的安全短名称与精确 commit id；branch 固定为
  `aezy/<name>`。
- 目标固定派生为
  `DSH_HOME/aezy/worktrees/<repository-name>-<common-dir-hash>/<name>`；HTTP 请求
  不能提供目标路径，也不解析 broad path、glob 或环境变量。
- 创建前验证 primary Local、base commit、branch 不存在、目标不存在、Git status
  和 conflict；dirty Local 需要 Web 明确确认，且只复制 committed base。
- creating、created、create-failed、session lifecycle、handoff、cleaned 都进入有界、
  原子持久的 repository registry event history。

### DSH Workspace / Session 薄接入

- Web `Worktrees` view 使用公开 `ctx.workspaces.create()`、
  `connectWorkspace()`、`ctx.sessions.open()` 建立并导航到 Worktree Session。
- Host 使用公开 `session/created`、`session/event`、`session/disposed` 维护绑定与
  active Turn 状态，不修改 Session header、API proxy、Subagent 或 Task 内核。
- 修复了旧 smoke 中被默认 cwd 掩盖的字段误用：DSH `WorkspaceView` 主键是
  `workspaceId`，不是 `id`。真实 HTTP 现在明确断言 Session cwd 等于 Worktree path。
- linked worktree 的 Git metadata/ledger 分离；不同 worktree 中重叠的 Turn 不会
  被标为共享 checkout 的 `concurrent`。

### 结构化 Handoff

每份 owner-only JSON handoff 包含：

- repository root、worktree id/path；
- branch、精确 base/head、ahead/behind；
- base → HEAD 的 committed file status（含 rename/copy previous path）；
- 当前 staged/unstaged/untracked/conflict working-file rows；
- clean 状态；
- 有界的 passed/failed/skipped validation results；
- 有界的接手说明、来源 Session 与生成时间。

Web 可查看/复制 JSON。`Handoff to Local` 先生成新记录，再调用 DSH 已有 archive
action、释放 Aezy binding，并打开 Local Workspace Session；它不 merge、push、
创建 PR 或删除 branch。

### Fail-closed cleanup 与 Security

cleanup 在以下任一条件下拒绝：

- 不是 Aezy registry 明确拥有的 worktree id；
- 目标逃离 repository-specific managed root；
- Git 不再注册该 path，或 path/branch 漂移、prunable/missing；
- 任一绑定 Session 仍 active，或 Turn 尚未结束；
- worktree dirty 或 conflict；
- 最新 handoff 不是 clean，或其 HEAD 与当前 HEAD 不同。

成功清理只执行不带 `--force` 的 `git worktree remove -- <exact-path>`，随后再次
检查 Git worktree list；branch 与 commits 明确保留。create/bind/handoff/release/
cleanup 都以 `user-confirmation` 进入 M2 Security audit。Agent 若试图绕过 Web 直接
调用 HTTP，仍受 loopback custom-header request fence 和 M2 shell/network policy。

## 已知边界

- Worktree lifecycle 是本地 Git 产品能力，不是 Cloud/SSH/Container provider。
- Handoff 是可审计接手事实，不自动 merge、push、PR 或 remote review。
- branch 永不由 cleanup 自动删除；保留 branch 的删除需要单独、明确的用户动作。
- archive/release 是产品级“当前 Session 不再拥有此环境”；DSH 的历史 Session log
  仍保留。
- M2 仍是 Agent tool boundary，不是 OS firewall；本里程碑没有改变该声明。
