`conversation.chat.turnTail` chain，在每轮最终 Assistant 回复下显示真实
Turn ledger 的文件摘要。首个 `/aezy/api/project/ledger` 请求会等待该 Session

摘要现为 Codex 式 change card：标题为 `Edited N files`，提供 `Undo` 与 `Review`，
显示总计和每个文件的 `+added -deleted`，文件行复用 DSH Host `openFile`。`Review`

无效打开，同 checkout 有重叠 Session 时显示 `concurrent` 并禁用整轮 Undo。
没有净文件变化的 Turn 不渲染卡片。数据源是 Turn 前后 Git
事实，不是工具名称或模型最终文本，因此覆盖 shell 修改/创建/删除，也不会把

修改；其系统提示与最终文本 inline file mentions 继续保留，只有工具推断的
