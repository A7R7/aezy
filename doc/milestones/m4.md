## 边界与上游复核

M4.1A 完全位于参考树外的 `@aezy/project` 中，没有修改
`.local/deepseek-harness/`，也没有复制 DSH Session、Task、Subagent 或 conversation
scroll 内核。

开工时重新检查了最新公开 tag `dsh-v0.1.1-rc.2`
（`b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`，tree
`53915efe4e2126cc7779b73dfc8a3bcec5318c44`）。rc.1 → rc.2 的
`ui-layout`、`ui-slots`、`ui-theme` 关键文件没有功能变化，`details` 仍是
`single/session` 且已由上游 Tool Details 占用，没有新增通用 panel router。

本轮因此不 shadow `details`，而是使用公开、additive、当前无官方 occupant 的
`shell.overlay` list slot。Aezy transient review controller 严格携带
`sessionId + cwd`，Session/Worktree 切换立即关闭不匹配的 surface。桌面 panel
右锚定并自行拖拽宽度，窄屏为全宽 overlay；不触发 conversation grid reflow，
也不读取或复制上游私有 scroll-anchor 实现。

## Host 与数据契约

Working changes 与 Historical Turn snapshot 现在投影为同一 version 2 DTO：

- file metadata：path、old/new path、modified/added/deleted/renamed/binary status、
  additions/deletions、truncated；
- staged/worktree/turn parts；
- hunks 与 context/addition/deletion/meta lines；
- 每行 old/new line number；
- malformed、combined、超行数或超长行输入 fail closed，hunks 为空，只暴露最多
  64 KiB 的显式 raw fallback；
- working identity 包含 repository root、path、fingerprint；client selection 再包含
  sessionId/cwd；historical identity 包含 sessionId、repository root、Turn、path、
  snapshot object id。

历史 raw unified diff 继续是 ledger object 的持久权威事实，结构 DTO 在读取时投影，
绝不根据当前 worktree 重算。`/turn-review` 现在必须带 path，只读取一个文件 object；
一个 Turn 中其他文件 object 损坏不会阻止打开当前文件。快速切换由
`AbortController + generation + active target identity` 三重门控，迟到响应不能覆盖
新选择。

M1 的 `change`、fingerprint、concurrent、batch preflight、receipt 和 fail-closed
Undo/Redo 语义未改变。M4 另存 review status/oldPath，使 clean tracked modification
不会在 Review UI 中伪装成 added，并能展示 Turn 内 rename；rename 仍不可安全撤销。

## Client 行为

- Turn card 不再请求或内联展开整 Turn raw diff；只保留 `Edited N files`、总/逐文件
  `+/-`、Undo/Redo、Review changes，以及 partial/concurrent/binary/truncated 状态；
- Review 或文件行在右侧 panel 打开对应 Turn/file；
- Working 与 Historical 来源标签显式区分；
- changed-file navigation 只请求当前文件；
- unified renderer 提供 old/new gutter、增删 status gutter、sticky file/part/hunk
  header、柔和增删背景，以及 added/deleted/renamed/binary/truncated/fallback 空状态；
- 所有颜色使用 DSH semantic theme aliases；
- close/Escape 只关闭 transient surface，不改变对话 view 或 scroll。
