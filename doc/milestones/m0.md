## 命令

```bash
pnpm install
pnpm run profile:sync
pnpm run test:m0
pnpm run aezy:web -- --host 127.0.0.1 --port 3080
```

Provider credential 应通过 Web 的 Models 设置写入 DSH 管理的 credential/settings 文档。Aezy 默认将这类运行状态保存在 `~/.aezy/dsh/`，不要提交到仓库，也不要粘贴到测试日志。若通过 `DSH_HOME` 覆盖位置，在 WSL 中应选择支持 owner-only Unix 权限的原生 Linux 文件系统，避免使用 `/mnt/c`、`/mnt/d` 等 Windows 挂载路径。
