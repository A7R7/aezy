# @aezy/brand

Minimal, out-of-tree occupants for the generic DSH Web brand slots. The
package renders the `Aezy` name and a temporary typographic `A` mark; it does
not introduce a permanent logo asset or modify the upstream official brand
package.

`@aezy/web` disables the upstream `ui-brand-official` row and inserts this
plugin instead. All colors follow DSH theme aliases.
