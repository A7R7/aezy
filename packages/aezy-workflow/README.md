# @aezy/workflow

Alpha-only, out-of-tree system macro-loop definitions and their thin DSH
compiler/runtime adapter. The first definition is `codex-inspired`.

This package does not implement a Session, model transport, tool dispatcher,
approval service, Security policy, usage ledger, compaction engine, Subagent
runtime, or PTY. It compiles a versioned immutable definition onto public
agent/tool extension seams already owned by DSH. The internal preset is absent
from the normal roster and remains unavailable unless an explicit dogfood
launch gate stages it.
